# Haps

Del din aftensmad med vennerne. Skriv om den kan anbefales eller bare er spiselig, og hap hinandens mad.

Appen ligger på https://kaspermoes.github.io/haps/ og kan lægges på iPhonens hjemmeskærm via Safari → Del → "Føj til hjemmeskærm".

- `index.html` – hele appen
- `sw.js` – gør appen installerbar og viser push-beskeder (hæv `CACHE`-versionen ved hver ny udgave)
- `supabase/` – backend: se `supabase/LÆS-MIG.md`

Demo uden login: åbn `…/haps/#demo`.
